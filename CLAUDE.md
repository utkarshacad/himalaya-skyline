# Notes for Claude

- Read `docs/CONTEXT.md` first. It holds the decisions and preferences from the original session.
- The owner (Utkarsh) wants **clarifying questions** on skill-based work so he can decide where he has an information gap. He may also say "take control".
- The game is the single file `index.html` with no build step. Keep it self-contained. MapLibre is the only external library.
- Visual direction (v3, approved art in `docs/art/`): PeakFinder at heart, in two themes: **dark "Summit Noir"** (charcoal ground, white ridge lines, flow lines on the summits) and **light "Ink & Mist"** (warm paper `#f6f3ec`, ink-wash ranges, fine ink lines; never pure white). Slanted labels and a **copper** accent `#b8734a` (chosen by the owner; **not pink, never yellow**). Spec: `docs/superpowers/specs/2026-11-15-webgl-renderer-v3-design.md` §2 and §10.2. The look matters most to the owner. Use round icon buttons in the corners. **Never add a panel that permanently covers the map**; panels open on demand.
- Smoothness is a hard requirement: panning, zoom, visibility and fly height never re-render on the processor. v3 draws the panorama on the GPU (`GLPano`, a polar mesh built once per viewpoint; every view change is a uniform). See "Panorama renderer v3" in `docs/technical-design.md`. Without WebGL2 the v2.4 strip renderer runs ("Render once, pan by sliding images").
- Rivers are a core feature: traced from terrain, and glinting.
- Before changing the renderer, read `docs/technical-design.md`. The same code in `#shared-src` (and `#mesh-src`) runs in both the page and the worker, so declare shared globals with `var`. Shaders live in `<script type="text/plain" id="glsl-*">` blocks.
- Test with headless Chromium: `cd tests && npm i && npm test` (or `node <name>.test.js`). The harness (`tests/harness.js`) serves the repo over http, routes the blocked MapLibre CDN URLs to `tests/node_modules/maplibre-gl` (5.24.0), and uses real Terrarium tiles (s3.amazonaws.com loads in the cloud sandbox). Use synthetic tiles only if the tile host is blocked. Software WebGL is slow: judge smoothness on a real device via https://utkarshacad.github.io/himalaya-skyline/.
